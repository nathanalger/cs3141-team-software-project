# CS3141 Team Software Project: Email Client

A project for MTU-CS3141 Team Software Project. The application is a frontend client with an API for communication with Google's SMTP and IMAP servers. Utilizes a Deno + Typescript + React + Vite tech stack.

## Getting Started

See [Getting Started](./getting-started.md).

## Start Local Vite Server

Finally, to start the local vite server, open the root folder (`cs3141-team-software-project`) in your terminal and run the following command:

```sh
pnpm lf
```

This will launch a vite server instance on https://localhost:5173/.
